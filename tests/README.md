# ชุดทดสอบความปลอดภัย

ทดสอบกับเซิร์ฟเวอร์จริง + PostgreSQL จริง (40 รายการ: ช่องโหว่ที่เคยพบ + การทำงานปกติของระบบ)

```bash
# 1) สร้างฐานข้อมูลเปล่าสำหรับทดสอบในเครื่องตัวเอง (ห้ามใช้ฐานข้อมูลจริง)
createdb acr_test
# 2) รัน
TEST_DATABASE_URL=postgresql://USER:PASS@localhost:5432/acr_test npm run test:security
```

- สคริปต์ปฏิเสธการรันถ้า DATABASE_URL ไม่ใช่ localhost และจะ **ลบข้อมูลทั้งหมด** ในฐานข้อมูลนั้นทุกครั้ง
- ไม่แตะ `.env` จริงของโปรเจกต์ (ส่งค่าทดสอบให้เซิร์ฟเวอร์เองผ่านตัวแปรสภาพแวดล้อม)
- ควรรันทุกครั้งก่อน deploy เวอร์ชันใหม่
